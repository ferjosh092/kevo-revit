# Planos estructurales – Casa San Jerónimo (rediseño 4 x 3)

Generados desde el modelo IFC `Proyect sj.ifc` (Revit 2027). Hoja A1, DXF editable (modelo en
metros reales + layout con ventanas a escala) y PDF.

| Lámina | Contenido |
|---|---|
| E-01 | Cimentación: planta, zapatas (planta y corte), viga de cimentación, cimiento de escalera, cuadro de zapatas |
| E-02 | Planta de columnas (replanteo), cortes generales, cuadro de niveles |
| E-03 | Columnas: secciones, elevaciones, traslapes, estribos y cuadro de columnas |
| E-04 a E-07 | Losa aligerada de los Niveles 2, 3, 4 y 5 |
| E-08 | Vigas de entrepiso: elevaciones por eje, secciones tipo y cuadro por nivel |
| E-09 | Escalera: plantas, cortes, cimiento de arranque y cuadro de acero |
| E-10 | Planilla de acero, metrados, especificaciones generales y observaciones |

Concreto f'c = 210 kg/cm² (estructurales), 175 (falso piso), 100 (solados); fy = 4200 kg/cm².
Antes de emitir: revisar `OBSERVACIONES_MODELO.md` (acero de vigas desplazado en el
modelo, losas macizas, límite de propiedad, recubrimientos en la escalera).
